# Switch accounts

- Click the account in the **status bar**.
- Use the **Claude Accounts** view in the Explorer.
- Press `Ctrl+Alt+Shift+A` (`Cmd+Alt+Shift+A` on macOS) to go back to the previous account.

Each window can use a different account. The Claude Code panel picks up the new account after the window reloads; the status bar shows a sync icon while a reload is pending.
