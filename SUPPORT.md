# Getting help

1. Run **Claude Accounts: Diagnose**. It shows which account each part of VS Code uses, checks every login with `claude auth status`, and lists setup issues with a fix for each.
2. Read [Troubleshooting](README.md#troubleshooting) and [Known limitations](README.md#known-limitations).
3. Questions and ideas: [Discussions](https://github.com/Kahuecosta/account-switcher-for-claude-code/discussions).
4. Bugs: [open a bug report](https://github.com/Kahuecosta/account-switcher-for-claude-code/issues/new/choose) with the diagnostics report.

Problems with Claude Code itself (logins, plans, usage limits) are for [Anthropic support](https://support.anthropic.com/).
